# 기획

## 한 줄 요약

기억력 대회 종목을 **초보용으로 쉽게 바꿔서**, 기법을 처음부터 배우고 매일 조금씩 연습하는 개인용 앱.

## 목표와 비목표

- **목표**: 장소법(기억의 궁전)과 숫자→이미지 변환을 몸에 익히기. 단어 10개 → 30개, 숫자 20자리 → 80자리처럼 늘어나는 걸 기록으로 확인하기.
- **비목표**: "머리가 좋아진다", "치매 예방" 같은 주장. 연구상 근거가 약해요 ([RESEARCH.md](RESEARCH.md)).
- **사용자**: 나 혼자, 안드로이드 폰. 로그인·서버·랭킹 없음.

## 핵심 루프

```
기법 배우기 → 종목 훈련 (외우기 → 떠올리기 → 채점) → 기록 확인 → 틀린 곳 장면 다시 만들기
```

하루 10~30분, 40일 커리큘럼을 기준으로 해요.

## 채점

- 단어·카드: 위치가 맞은 개수 (대회처럼 순서가 중요).
- 이미지 순서: 위치가 맞은 그림 개수.
- 듀얼 N백: 맞힌 비율(%) = 맞힘 / (맞힘 + 놓침 + 잘못 누름). 기록 그래프는 단계(N)를 그림.
- 숫자: 위치가 맞은 숫자 개수. (대회는 줄 단위 채점이 더 엄격함 — 나중에 '대회 채점' 옵션으로 추가 가능)

## 화면 흐름

```
홈 ─┬─ 훈련: 단어 / 숫자 / 카드 / 숫자 사전 훈련
    │     설정 → 외우기(타이머) → 떠올리기 → 결과(저장)
    └─ 준비: 내 궁전 / 숫자 사전 / 기법 배우기 / 기록
```

## 기술 결정

- **PWA + 순수 JS**: 빌드 없이 VS Code에서 바로 고치고, GitHub Pages에 올려 폰에 설치. 앱스토어 등록 계획이 없어서 이게 제일 가벼움.
- **localStorage**: 데이터가 작음(기록 최대 500개). 커지면 IndexedDB로.
- **APK가 필요해지면** Capacitor로 감싸기 (README 참고).
