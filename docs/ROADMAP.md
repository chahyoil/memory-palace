## 기술 부채 / 메모
- 기록이 커지면 localStorage → IndexedDB
- `sw.js` 의 `CACHE_VERSION` 을 매번 손으로 올리는 대신 빌드 스크립트로 자동화
- 대회식 숫자 채점(줄 단위) 옵션
- 1분 도전의 최고 기록은 지금 종목 전체 최고와 비교함 → 같은 설정끼리 비교하도록 나누기
- 진짜 1:1 대전은 서버가 필요해서 하지 않음 (개인용·오프라인 원칙)
- 단계 난이도는 직접 해 보면서 조정 필요 (`src/data/stages.js` 숫자만 바꾸면 됨)
- 다크 모드에서 세계 색·히어로 색 대비 실제 폰으로 확인하기
